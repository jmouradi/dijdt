# DIJDT: Did I Just Do That?

A simple page you can bookmark on your mobile phone to help you remember if you did something.

## Requirements

A web browser with local storage. Written in Nov 2026.

Layout intended for mobile phones.

## Instructions

To add a task or item to track, enter its name in the text box and click "Add Item".

To log when you performed this task, press the button with its name. Its last-pressed time will appear to the right.

To remove a task or item to track, enter its name in the text box and press "Remove Item".

To clear an annoying red error, press "Clear Error".
